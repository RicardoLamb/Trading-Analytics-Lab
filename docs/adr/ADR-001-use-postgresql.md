# ADR-001 - Use PostgreSQL

## Status

Accepted

## Context

Trading Analytics Lab requires a relational database capable of handling transactional data, analytics queries, future scalability, and cloud deployments.

## Decision

PostgreSQL will be used as the primary database.

## Consequences

### Positive

- Open source
- Mature ecosystem
- Excellent .NET support
- Strong Docker support
- Cloud provider compatibility
- Advanced querying capabilities

### Negative

- Requires database administration knowledge
- Slightly higher learning curve compared to embedded databases
